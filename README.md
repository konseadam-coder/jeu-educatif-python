**Jeu Éducatif Interactif**

I - *Description*
Ce projet est un jeu vidéo éducatif développé dans le cadre d'un projet universitaire.
L'objectif est de rendre l'apprentissage ludique pour les enfants
en utilisant les concepts de la Programmation Orientée Objet (POO).

II - *Technologies utilisées*
* Langage : Python 3
* Concepts : Programmation Orientée Objet (Classes, Héritage, Polymorphisme)
* Éditeur : VS Code sous environnement Linux

III - Fonctionnalités principales
* Interface interactive pour les utilisateurs.
* Différents niveaux de difficulté adaptatifs.
* ()

Comment lancer le projet (Installation)
1. Cloner le dépôt : `git clone https://github.com/konseadam-coder/nom-du-depot.git`
2. Ouvrir le terminal et naviguer dans le dossier.
3. Exécuter le script principal : `python3 main.py`
